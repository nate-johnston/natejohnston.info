Since I have become an Engineering Manager, I have found that my interest in
doing system administration of my own stuff has waned.  That is why I now run
Mac OS X instead of Fedora for my work laptop, among other things.  Well, now I
am looking to downsize the VMs that I maintain myself.

To that end, I am moving this website to GitHub Pages.  Let's see how it goes.
Since this is a Hugo driven site, I am using the instructions [located at
gohugo.io](https://gohugo.io/host-and-deploy/host-on-github-pages/).
